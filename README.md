<h1 align="center">Consort</h1>

<p align="center">An agentic development workspace for running focused AI work in real Git worktrees.</p>

## What it does

- Keeps projects, branches, chats, terminals, diffs, commits, and PR reviews in one desktop workspace.
- Creates isolated worktrees so agents can work without disturbing your main checkout.
- Supports Claude Code and Codex connectors, with model selection per chat.
- Turns PR reviews into review artifacts you can approve and post to GitHub yourself.

## Run locally

```bash
pnpm install
pnpm dev
```

Create a project, open a worktree, start a chat, and let Consort keep the work organized.
